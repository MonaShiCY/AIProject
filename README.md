# AIProject

This repository contains a SwiftUI component library home screen. Follow the steps
below to preview the interface inside Xcode.

## Online/Live Preview

1. Open the project workspace or package in **Xcode 15** (or newer) on macOS.
2. In the project navigator, locate
   `Sources/ComponentLibraryUI/ComponentLibraryHomeView.swift`.
3. Open the file and make sure the Canvas (right-hand preview pane) is visible by
   selecting **Editor ▸ Canvas**.
4. If the preview is paused, click **Resume**. Xcode will compile the view and
   display the live SwiftUI preview.
5. Use the preview controls to switch between light/dark mode or interact with
   the layout in real time.

> **Tip:** If the preview fails to load, run the view in the simulator once (using
`⌘R`) to resolve any build issues, then return to the Canvas.
